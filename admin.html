Edit your show's content and publish updates to GitHub Pages.

Publishing & security: This is a local content editor, not a password-protected server admin. Edits stay in this browser until you download data.json and upload it to your GitHub repository. Do not put private information or passwords here. View public site.

📣 Announcement

Publish: In your GitHub repository, choose data.json → edit/upload replacement → commit changes. Your live website will show the new content once GitHub Pages redeploys.
